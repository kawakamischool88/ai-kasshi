# PDFで使う日本語フォント

振り返りPDF（Phase 4C）で使います。

| ファイル | 用途 |
| --- | --- |
| `MPLUS1p-Regular.ttf` | 本文・見出し（1つだけ） |
| `OFL.txt` | ライセンス本文 |

## なぜこのフォントか

- **M PLUS 1p**（M+ Project）／ SIL Open Font License 1.1
  - 配布・埋め込みが認められている（OFL.txt のとおり）
- **TrueType 形式**。PDFを作る部品（pdf-lib）がそのまま扱える
- 約1.7MB。日本語フォントとしては小さい
- **太字は入れていない。** フォントを丸ごと埋め込むため、太字を足すとPDFが倍になる。
  見出しは大きさ・色・下線・帯で見分ける
- 日常の日本語・人名・地名をひと通り表示できることを確認済み

Windows に入っているフォント（游ゴシック・メイリオ等）は、
**配布が認められていない**ため使いません。

## 注意：フォントは丸ごと埋め込む（subset しない）

「使った文字だけを抜き出して埋め込む」やり方（subset）は**使いません**。

実際に試したところ、**文字の形（グリフ）がごっそり抜け落ち、
PDFを開くとほとんどの文字が真っ白**になりました。
文字を取り出すと正しく読めてしまうため、気づきにくい不具合です。

そのためPDFは約1MBになりますが、**読めないPDFを渡すよりずっとよい**と判断しました。
やり方を変えるときは、必ず**実際にPDFを開いて目で確かめて**ください。
